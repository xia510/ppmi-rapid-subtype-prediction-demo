# DeepSeek 科研辅助解读设计

## 目标

为已有的本地预测增加可选的中文解释能力，同时保持 Logistic Regression 是唯一的预测来源。

## 数据流

网页先调用本地 FastAPI 预测。用户确认后，网页调用 `POST /explain`；后端重新执行本地预测并从结果中筛选概率、阈值、研究标签和特征名/贡献度，再请求 DeepSeek。原始 12 项特征和 `patient_id` 不进入 DeepSeek 请求。

## 失败处理

缺少 `DEEPSEEK_API_KEY` 时返回 503；DeepSeek 网络或响应错误时返回 502。网页展示可读错误，不影响原有本地预测功能。

## 安全边界

密钥只从 API 服务进程的环境变量读取，`.gitignore` 已排除 `.env`。系统提示禁止大模型给出诊断、治疗或因果结论，并在输出后重复科研演示免责声明。

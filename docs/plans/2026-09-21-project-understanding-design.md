# 项目理解文档设计

## 目标

新增仓库根目录 `理解项目.md`，面向刚开始学习 AI 应用工程的读者，按照项目真实执行顺序解释每个目录、文件、主要函数、数据结构及文件之间的调用关系。

## 内容顺序

1. 先建立项目全景、目录地图和两条主流程（模型导出、在线预测/解读）。
2. 按“研究 CSV → 模型包 → 本地预测 → FastAPI → Streamlit → DeepSeek → 配置/日志 → 测试”顺序逐文件讲解。
3. 对关键函数说明输入、处理、输出、调用者与依赖对象，不机械复制完整源码。
4. 用真实字段示例解释 `model_bundle.joblib`、患者请求、预测响应、DeepSeek 请求和结构化响应。
5. 补充数学直觉、隐私边界、常见误区、状态码排错、阅读顺序、自测题和动手练习。

## 边界

- 只新增文档，不改变运行代码、依赖或模型行为。
- 说明必须以当前 `main` 对应代码为准。
- 不写入训练数据、真实患者数据、API Key 或个人绝对路径。
- 明确该项目仅用于科研复现和工程学习，不用于临床决策。

## 验收标准

- 根目录存在 `理解项目.md`。
- 当前主要源文件和测试文件均在文档中得到说明。
- 文档包含完整调用链、关键公式、错误流、隐私流和学习练习。
- Markdown 无尾随空格错误，现有 26 项自动化测试继续通过。
